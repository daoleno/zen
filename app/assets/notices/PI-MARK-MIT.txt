Pi Coding Agent brand mark
==========================

Zen ships a compact React Native SVG of the Pi Coding Agent mark used by the
shared AgentKindIcon component.

Provenance:
- Official geometry: https://pi.dev/logo.svg and https://pi.dev/logo-auto.svg
  for the badlogic/pi-mono / Pi Coding Agent project (MIT).
- Matching 24x24 Mono paths: LobeHub lobe-icons src/Pi/components/Mono.tsx
  (MIT). @lobehub/icons-rn@2.7.1 does not export a Pi component, so Zen mirrors
  those open-source paths locally as app/components/icons/PiMark.tsx.
