# Zen v0.1.9

This release contains the reviewed changes on `main` since `v0.1.8`.

## Release context

This release removes the Amp agent interface. Amp is no longer presented as a
disabled peer in the Session quick-launch list, the Brain and Worker executor
selectors, or the executor mention picker, and its BYOK boundary document is
deleted. A custom `[[executors]]` entry or command named `amp` now behaves as an
ordinary custom tmux executor with no structured chat, native resume, tool
events or credential routing. Pi and OpenCode commands and defaults are
unchanged.

## Known limitations

- iOS Preview tester availability remains subject to Apple's processing and Beta App Review. A successful signed build and TestFlight upload do not alone guarantee external tester access.

## Install

Download `zen-linux-amd64.tar.gz`, `zen-linux-arm64.tar.gz`, or `zen-darwin-arm64.tar.gz` for your host, plus the Android APK and `SHA256SUMS`. Extract the archive, install `zen` on your `PATH`, run `zen`, then create a pairing link with `zen pair https://your-origin`.

Apple Silicon support requires `tmux` (`brew install tmux`). The macOS binary is cross-built; validate it on a real Apple Silicon host before operational use.

The iOS Preview is distributed through TestFlight at <https://testflight.apple.com/join/rTKCDzMt>, subject to Apple's beta approval and processing.
