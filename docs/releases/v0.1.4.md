# Zen v0.1.4

This release contains the reviewed changes on `main` since `v0.1.3`.

## Highlights

- Brain and Workers deliver completion and original results more reliably, preserve ambiguous recovery outcomes for review, and follow live Codex transcript switches. Work defaults to delivery in the owning repository.
- Brain event cards preserve Unicode summaries and filter internal lifecycle events from the conversation.
- Git Diff supports staged, working-tree and combined comparisons with continuous reading, full-comparison search, and per-file reading positions. Update both the mobile client and its current daemon for the paged Git review protocol.
- Interface chat retains reading anchors through history updates, navigation, reconnects and keyboard changes, while keeping follow-latest an explicit reading intent.
- Stats refreshes provider-aware reference prices automatically, applies supported Codex context tiers per request, and distinguishes reported charges, estimates and unknown prices. Settings groups Channels more clearly and removes redundant identity and navigation copy.

## Known limitations

- The reported first-image crash/reload remains unreproduced and is **not fixed** by this release. The earlier native Fabric cold-entry crash also remains unresolved. Reading and image-preview test improvements are not proof of a release-device crash fix.
- iOS Preview availability remains subject to TestFlight processing and any required Apple Beta App Review; a successful archive or upload alone does not mean external distribution is available.

## Install

Download `zen-linux-amd64.tar.gz`, `zen-linux-arm64.tar.gz`, or `zen-darwin-arm64.tar.gz` for your host, plus the Android APK and `SHA256SUMS`. Extract the archive, install `zen` on your `PATH`, run `zen`, then create a pairing link with `zen pair https://your-origin`.

Apple Silicon support requires `tmux` (`brew install tmux`). The macOS binary is cross-built; validate it on a real Apple Silicon host before operational use.

The iOS Preview is distributed through TestFlight at <https://testflight.apple.com/join/rTKCDzMt>, subject to Apple's beta approval and processing.
