# Zen v0.1.0-beta.3

This beta strengthens Brain's product story, improves Chat timeline following, and opens the iOS Preview path through TestFlight.

## What changed

- Brain is described as the persistent place that keeps objectives, decisions, open threads, and next steps together across chats and restarts.
- Chat follows new and streaming messages while the reader is at the bottom, but preserves the reader's position after they intentionally scroll away.
- The iOS Preview workflow now builds with Xcode 26, validates Push Notifications signing, and uploads through Apple's Build Upload API.
- A public TestFlight invitation is configured at <https://testflight.apple.com/join/rTKCDzMt>. The first external build still requires Apple Beta App Review before new testers can install it.

## Install

Download `zen-linux-amd64.tar.gz`, `zen-linux-arm64.tar.gz`, or `zen-darwin-arm64.tar.gz` for your host, plus the Android APK and `SHA256SUMS`. Extract the archive, install `zen` on your `PATH`, run `zen`, then create a pairing link with `zen pair https://your-origin`.

Apple Silicon support requires `tmux` (`brew install tmux`). The macOS binary is cross-built and should be treated as beta until it has completed broader real-device testing.
