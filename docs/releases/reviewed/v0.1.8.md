## Release context

This version follows the unpublished GitHub Release candidates v0.1.6 and v0.1.7. Both source tags remain unchanged. Android SDK setup now requests supported packages, Linux release builds install their native development dependencies, and Android builds prepare the pinned Moonlight sources and OpenSSL prefix before compilation.

## Highlights since the last public release

- The Remote Desktop entry is temporarily hidden from the navigation drawer. Its route and native implementation remain in the app.
- Clean native CI now covers compilation of the production daemon targets and Android debug/release APKs.

These highlights include the unpublished candidates since public v0.1.5. The generated commit list below records changes since the preceding source tag.

## Known limitations

- iOS Preview tester availability remains subject to Apple's processing and Beta App Review. A successful signed build and TestFlight upload do not alone guarantee external tester access.
