# Zen v0.1.0-beta.6

This beta focuses on reliable mobile agent sessions, explicit resource ownership, and a secure release-to-update path.

## What changed

- Interface chats now stream structured turns incrementally, keep input acknowledgements nonblocking, and recover pending sends and provider activity without duplicating or losing conversation state.
- Terminal sessions have more reliable project/session ownership, live-grid rendering, scrolling, keyboard and focus behavior, and native/resource diagnostics across Android and iOS.
- Brain, Calendar, and delegated-executor actions keep scheduled results, unread state, notifications, resource snapshots, and executor changes attached to the intended thread or Session.
- Mobile navigation, sheets, tables, tabs, and session controls received interaction and visual reliability fixes.
- The daemon installer now selects the highest supported public Zen release, while signed manifests enable authenticated in-place daemon updates.
- One annotated beta tag now owns verified daemon archives, the signed Android prerelease, and the automatic iOS Preview TestFlight workflow.

## Install

Download `zen-linux-amd64.tar.gz`, `zen-linux-arm64.tar.gz`, or `zen-darwin-arm64.tar.gz` for your host, plus the Android APK and `SHA256SUMS`. Extract the archive, install `zen` on your `PATH`, run `zen`, then create a pairing link with `zen pair https://your-origin`.

Apple Silicon support requires `tmux` (`brew install tmux`). The macOS binary is cross-built and should be treated as beta until it has completed broader real-device testing.

The iOS Preview remains available through TestFlight at <https://testflight.apple.com/join/rTKCDzMt>, subject to Apple's beta approval.
