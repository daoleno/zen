# Zen v0.1.0-beta.8

This beta expands self-hosted Skills and file workflows while tightening mobile server, upload, conversation, and release ownership.

## What changed

- A new Skills surface can inspect and manage Skills on the current Zen server, with clearer local, catalog, validation, and terminal handoff behavior.
- Session file previews now cover supported text, image, patch, and PDF content through bounded daemon reads and shared mobile presentation.
- Large attachment uploads now report progress, support cancellation, and respect the current-server boundary across screen changes and server switches.
- Interface, navigation, sheets, inputs, logo contrast, and terminal accessory controls received mobile interaction and accessibility refinements.
- Structured conversations and Codex-derived activity parsing preserve more stable current-server, pending-turn, tool, and edit ownership.
- Selecting message text on Android no longer lets native descendant focus move the inverted conversation viewport; native selection and copying remain enabled.
- Release CI now restores the pinned Ghostty JNI header with its Android libraries and rejects an incomplete native-output cache before signed APK compilation.

Automated App, daemon, release-identity, native-contract, and Android/iOS bundle checks cover this source. The text-selection correction has deterministic native-contract and regression coverage, but this release session does not claim physical-device verification.

## Install

Download `zen-linux-amd64.tar.gz`, `zen-linux-arm64.tar.gz`, or `zen-darwin-arm64.tar.gz` for your host, plus the Android APK and `SHA256SUMS`. Extract the archive, install `zen` on your `PATH`, run `zen`, then create a pairing link with `zen pair https://your-origin`.

Apple Silicon support requires `tmux` (`brew install tmux`). The macOS binary is cross-built and should be treated as beta until it has completed broader real-device testing.

The iOS Preview is distributed through TestFlight at <https://testflight.apple.com/join/rTKCDzMt>, subject to Apple's beta approval and processing.
