### First-party meditation bed (reproducible generation)

Canonical generator: **`./scripts/generate-meditation-ambient.sh`** (writes `app/assets/audio/meditation-ambient.m4a`). Lightweight checks: **`./scripts/generate-meditation-ambient.sh --verify`**.

**Design (pinned in the script):**

| Parameter | Value |
| --- | --- |
| Duration | 60 s |
| Sample rate / channels | 44100 Hz mono |
| Noise | `anoisesrc` pink, amplitude 1, **seed `20260712`**, `nb_samples=1024` |
| Noise EQ / gain | `lowpass=f=280`, `highpass=f=70`, `volume=0.07` |
| Sine pads | 98 / 147 / 196 Hz at volumes 0.018 / 0.012 / 0.008 |
| Mix | `amix=inputs=4:duration=first:dropout_transition=0` |
| Fades | 4 s in, 4 s out (out starts at t=56 s) |
| Encode | AAC `96k`, `-movflags +faststart` |

**Command:**

```bash
./scripts/generate-meditation-ambient.sh
```

Equivalent filter graph is the single ffmpeg invocation in that script (do not re-type ad hoc flags in CI docs—edit the script).

**Reproducibility note:** The noise seed and all filter/encode parameters are fixed so repeated runs with the **same ffmpeg/libavcodec version** produce stable content as far as the encoder permits. Do **not** claim byte-for-byte identity across ffmpeg or AAC encoder versions (bitstream, container metadata, and timestamps may differ). Provenance is the script + this design table, not a hash pin.

## Native dependency: Ghostty VT

| Artifact | Upstream | License | Notes |
| --- | --- | --- | --- |
| `libghostty_vt.so` (Android) / `ghostty-vt.xcframework` (Apple input) | [ghostty-org/ghostty](https://github.com/ghostty-org/ghostty) | [MIT](https://github.com/ghostty-org/ghostty/blob/main/LICENSE) | The exact `libghostty-vt` C ABI component is built via the platform scripts from the immutable pin in `app/modules/zen-terminal-vt/native.lock.json`. Binaries are gitignored; the Apple artifact is not linked until the iOS bridge is complete. |
| Notice source | same | MIT | `app/assets/notices/GHOSTTY-MIT.txt` embeds the pinned Ghostty `LICENSE` body (`license_sha256` in `native.lock.json`). Module pointer: `NOTICE.Ghostty`. |
| Notice in APK | same | MIT | Expo plugin `withZenAndroidRelease` copies the notice to `android/app/src/main/assets/notices/GHOSTTY-MIT.txt` → APK path `assets/notices/GHOSTTY-MIT.txt`. Verify: `./scripts/verify-apk-notice.sh <apk>`. |

**ABI contract:** only `arm64-v8a` (device/sideload) and `x86_64` (emulator). See [android.md](android.md).

**Redistribution:** APKs must embed the MIT notice (path above). Prebuilt `.so` archives should include an adjacent `GHOSTTY-MIT.txt` (written next to libs by `build-libghostty.sh`).

## npm / Go dependencies

Application and daemon library licenses are those of their respective packages (`bun.lock`, `daemon/go.mod`). This document focuses on **bundled media and vendored native binaries**, which are easy to miss in automated SCA.
